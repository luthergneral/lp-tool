# Landing Page Test Tool (LPTT)

The goal of this single plage site is to provide designers a visual preview of the landing page they are designing—specifically the hero image (PNG) and background image—to help them assess visual appeal and reduce the need for update requests.

<hr>

## How It's Made:

**HTML | CSS | JavaScript**

- The site uses basic HTML and CSS coding. The heavy-lifting is performed using JavaScript. While what is being asked is simple, the challenge lies in breaking the script code into smaller chunks.

### Functions ###
- Below are the hard requirements for this project:
    - Must be a single file/one-pager that works without requiring office network or VPN.
    - Ability to select between different states and sites.
    - Option to choose the hero image position: left, center, right
    - Shows preview for both desktop and mobile views.
